# Карта рисков трансформации «Будущее 2.0»

Оценка по шкале **Н / С / В** (низкая / средняя / высокая). Уровень риска = комбинация вероятности и влияния (В+В → критический, В+С/С+В → высокий, С+С → средний, остальное → низкий).

## Архитектурные риски

| ID | Риск | Вероятность | Влияние | Уровень |
|----|------|:-----------:|:-------:|:-------:|
| A1 | Бизнес-логика «зашита» в DWH — сложно вынести в домены без потери поведения | В | В | Критический |
| A2 | Рост сложности из-за событийной модели (итоговая согласованность, дубли, порядок) | С | В | Высокий |
| A3 | «Дырявые» границы доменов: связность сохраняется через общие данные | С | С | Средний |
| A4 | Несовместимость контрактов событий между версиями | С | С | Средний |
